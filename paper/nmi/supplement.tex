\section*{Supplementary Note 1: the first deployment run and its audit}

The first full run of the deployment experiment began on 25 October 2026 under the author's own macOS account. Biomni's system prompt lists its data-lake directory, and that directory sat inside the study's repository, so the path shown to the model contained the strings \texttt{bioagent-plausibility} and \texttt{biomni\_spike}. Biomni's code executor was not sandboxed: code the agent wrote could read the author's filesystem and reach the internet, and the study's repository was public.

After the run, every transcript was audited with three regular expressions, recorded in \path{results/analysis/audit_biomni_environment.py}: \emph{awareness} (phrases inferring a plausibility benchmark, a test, or an evaluation of the agent), \emph{repository pattern} (code executions referencing the author's home directory outside the data lake, the study's repository files, \texttt{git} commands or process listings) and \emph{metadata vocabulary} (terms from the study's task files, such as \texttt{corrupted\_value} or ``answer key''). DeepSeek V4.1 Flash matched none of the first two in any run and the third in one run (u015), which caught the corruption regardless. Gemini 3.8 Flash matched awareness in 44 runs, the repository pattern in 98 and the vocabulary in 2. Aware runs behaved differently: Flash's aware runs relayed plausible values in 1 of 23 delivered runs, against 68 of 265 for the others. Awareness does not account for the difference between the runs, however: both models relayed plausible values less often in the rerun (Gemini 3.8 Flash 21\% against 24\%; DeepSeek, which showed no awareness, 17\% against 28\%), which indicates run-to-run variation of about ten points in this setting. We report the rerun as registered, and both runs gave the same direction for the derivation-route hypothesis (odds ratios 5.7 and 17.2 for DeepSeek, 3.6 and 6.9 for Gemini 3.8 Flash; Supplementary Table 1). The external files Flash fetched were Biomni's own repository (its evaluation task list) and a third-party benchmark (Bio-Bench); no transcript shows the study's files being read.

The corrupted conditions were rerun on 3 November 2026 under a second macOS user with no read access to the author's home directory, with the data lake at a neutral path (\path{/Users/Shared/agentrun/workspace}). The agent's state file carried only the task identifier and a slot number; the mapping from slot to condition (\path{harness/rerun_schedule.json}, commit 0019d72) was read by the proxy and never shown to the agent. The clean runs were retained from the first run. In the rerun no transcript named the study, its repository or its paper. DeepSeek matched no pattern in any run. Flash matched awareness in 16 runs, each inferred from the task and the anomaly themselves rather than from the environment, the repository pattern in 17 runs of directory and process probing that found nothing, and the vocabulary in 2; the external files it fetched were again Biomni's own repository and Bio-Bench. Supplementary Table~1 gives both runs side by side; the main text reports the rerun throughout.


\section*{Supplementary Note 2: registration and run timestamps}

Each registration was committed before the runs it concerns; the intervals were: new-field experiment, commit 2059c3a, three minutes before the first run; its agreement follow-up, 217ea9d, one minute; superseded-sequence experiment, ac99248, 24 seconds; robustness addendum, 6830c57 and 76e56b6, 13 minutes and one minute before the respective runs; deployment hypotheses, OSF draft four minutes before the first full run, cited by commit a2dc4a4 two minutes before the runs; memory probe, 74415d3, and the prompt, repetition and withholding experiments, 499d317, each committed before the runs they concern on 3 November 2026. The registrations added in revision were committed as follows: the coherent corruptions, f97e2d2, with addenda 67859f8 and 5acb36f committed before the runs they added; the deployment rerun's slot schedule, 0019d72, the evening before the rerun on 3 November 2026; the identity, reasoning, no-concerns and duplicate-field experiments, 9234013, two minutes before the first run; their addenda, c4f1f43 and cfbf0a7, five and four seconds before the respective runs; the unprompted-doubt classifier prompt, f5cae56, four minutes before it was first applied; and the held-out validation sample with the classifier's answers, 6964e2e, ten minutes before the independent labels were committed. The OSF registration (osf.io/jmwab) was submitted on 1 November 2026 at 21:49 UTC, after the first full run and before the rerun. Run times are taken from the creation times of the result files. Commit times are recorded in the repository history.
