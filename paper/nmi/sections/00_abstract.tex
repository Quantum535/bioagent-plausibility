\begin{abstract}
Agents that query scientific databases are trusted to reason over records, yet databases contain errors. We asked when agents relay a wrong database value. In a live deployment of Biomni and a ten-model benchmark, agents detected errors and relayed them anyway. What decided override was not plausibility but whether another field of the record contradicted the value: 79 superseded UniProt records, internally consistent, were relayed in 90--100\% of runs, and agents that computed the correct value from a record's formula still answered from the record. Instructions removed relay only where the record contradicted the value; an output format that asked for the agent's own estimate let memory correct consistent errors; withholding a field that failed a check or correcting the record silently from a second source removed relay (0 of 709 and 0 of 702 runs). Conflicts should be resolved before the agent reads the record.
\end{abstract}
