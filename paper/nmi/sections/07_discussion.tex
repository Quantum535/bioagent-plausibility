\section*{Discussion}

Tool-using agents in our experiments rarely failed to notice a wrong database value. They failed to act on what they noticed. Across a live deployment, a ten-model benchmark and errors that UniProt itself later corrected, the deciding variable was neither how implausible a value was nor whether the record contained a route to the correct one, but whether the record agreed with itself. A value contradicted by another field was often overridden. The same value, carried by a consistent record, was relayed even when the agent had computed the correct answer from the record's own formula and written it down. Real errors arrive in this second form: a superseded sequence is consistent with its own length and mass, and 90--100\% of such values passed through every model we tested, whatever the size of the revision.

The further experiments say what agreement means and where relay comes from. Agreement is the absence of contradiction. A second copy of a wrong value did not strengthen it (relay fell), a derived field that agreed added a few points, and a single field that disagreed removed relay almost entirely. Where the record did contradict the value, much of the relay was instruction. The registered prompt asked agents to use the provided tools, and they did, literally: dropping that sentence halved relay on the chemistry cells, and a sentence naming the formula as authoritative removed it. Where the record did not contradict the value, no instruction had any effect, because there was nothing in the record for an instruction to point at. What did reach those errors was the shape of the answer. Asked for the database value and their own best estimate as separate fields, two of three models answered from memory and relayed coherent errors in 52\% and 0\% of runs instead of 96--98\%. The memory probe explains why this works and where it stops: the models hold the current value for most proteins, that memory loses to an unchallenged record (91--100\% relay even when memory was right), and it decides the matter once a conflict is visible, in whichever direction it points.

Agents increasingly sit between such databases and downstream analyses, and their answers are often read by programs rather than people. In that setting a raised concern is easy to lose: the answer field carried the record's value, while the correct value, when the agent had found it, sat in a separate remark.

Work on knowledge conflicts has shown that language models adopt incorrect context readily, even against their own memory \citep{xu2024conflicts,wu2024clasheval,xie2024adaptive}, and concurrent work shows that tool-using agents adopt corrupted tool returns and may question a return while passing it on \citep{yang2026overreliance}. Those studies corrupt single returned values. Our results identify what governs the outcome when the value sits in a structured record: whether any field of the record disagrees with it. Disagreement can be varied without touching the wrong value, and doing so moved relay by up to 32 percentage points; an error can be made invisible by recomputing the fields around it; and errors that actually occurred in a production database arrive in exactly this form. Values that looked like placeholders were replaced, so implausibility matters at the extreme, but within the range of values that look like data, consistency decides. The behaviour is not a weighting of evidence by repetition, which lowered relay, and only partly a trained deference to tools, which the prompt could switch off; it is a sensitivity to contradiction, acted on when the instructions or the output format give the agent a reason to.

Three implications follow for systems that put agents on scientific databases. First, what an agent is asked to output matters as much as what it is told. An instruction can remove relay of errors the record contradicts, and an output format that separates the record's value from the agent's estimate lets a correct memory act on errors it does not. Neither reaches an error that is consistent with its record and absent from memory, and for errors a database has not yet corrected, memory may hold the error itself (8--9\% of our historical proteins). For those, the remedies act on the record before the agent reads it: a second source, or a withheld field. Withholding any derivable field that fails a check, with no note, removed numeric relay entirely (0 of 583 fields), and unlike an annotation it left the agent nothing to disregard. Second, how a correction is presented matters as much as whether it is made. Showing the agent both values reopened a decision that silent correction had closed: one model chose the value labelled as the original in 41\% of runs, and others resolved the conflict from memory. Reliability labels on retrieved content modestly reduce adoption \citep{yang2026overreliance}; a label identifying the original database value, by contrast, raised relay in one model. The design principle is to resolve conflicts before the model sees them, with the audit trail kept for the people responsible for the analysis. Third, a second source must be chosen for agreement and coverage, not convenience. A source that disagrees with the primary database even 5\% of the time would, applied silently, insert errors into clean records, and entities outside its coverage remain blind spots.

Our study has limits. Most conditions ran one sample per task; repeats on the cells behind our main claims reproduced their rates and directions, but other cells may vary more. We studied two domains, two primary databases and question formats with a single checkable answer; open-ended analyses may behave differently. All errors except those in the UniProt archive were constructed, and the historical records carried current annotations (Methods). The deployment used one agent framework and two models, and its first run was contaminated by the environment and repeated (Methods). The prompt, repetition, memory and withholding experiments used three or four models and a subset of cells. Model behaviour is tied to the versions we tested, all from 2026. Several experiments were designed after earlier results in the same study and registered before they ran; of the registered predictions, two failed in the direction we had predicted and we report each. Our cue classifier agrees with human consensus at $\kappa = 0.65$--$0.87$, not perfectly.

The agents we studied behaved less like credulous readers than like careful clerks: they noticed discrepancies, noted them, and recorded what the database said. For a clerk that is often the right policy. For an agent whose answer feeds an analysis, it means that database errors become analysis errors unless the record is corrected before the agent reads it, or the agent is asked, in so many words, for its own estimate.
